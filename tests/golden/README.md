# 黄金测试集

用于对比：纯 LLM vs RAG + 确定性检查。
每条案例应包含：广告图转录文本、人工评审结论、阻塞项列表。

## 案例 1：RC-20261104-001 v1（借 5 万 / HK$805 / 1.15% / HK$80,000 回赠）

- 整体结论：不建议发布，高风险
- 关键阻塞：
  - 借 5 万、月供 HK$805 缺还款期及计算条件；按 1.15% 反推约 64 个月，非 常规期限，需底稿验证
  - 无法证明 HK$805 与 APR 1.15% 属于同一示例
  - HK$80,000 回赠资格、计算条件不足；回赠大于借款额，并排易误导
  - 限时推广无日期
  - 忠告显著性无法从位图确认，需源档复核
  - 脚注、牌照、热线手机端可读性存疑
  - 图中有“画板 4”、重复水印、底部残边

## 案例 2：MARLEY-BLIND-20261106-001（高达 HK$80,000 回赠 / 1,000,000 / 72 期）

- 整体结论：不建议发布，高风险
- 关键阻塞：
  - 80,000^ 没有对应的 ^ 脚注，回赠条件完全缺失
  - 图上完全没有利率信息，无 APR、无月供示例，无法比较成本
  - 最高贷款额与最长期适用范围不足，共用通用免责
  - 忠告显著性无法从位图确认
  - 牌照、公司名、热线字小，手机端可读性存疑
- 通过项：无画板、水印残留

## 评估指标

- 阻塞项召回率：人工列出的阻塞项，模型抓到多少
- 误报率：模型多判了多少不存在的问题
- 引用正确率：每条发现是否引到原始条款
- 不确定性处理：该写“无法确认”的地方，模型有没有硬编数字
