# 合规评审系统（v1）

这是你要的「系统」，不是只有 md 文档：一个能跑起来的评审工具，
上传广告图 + 粘贴转录文字，就能出确定性检查结果、APR 反推和 RC 草稿报告，
还能建档、留历史、人工签核，改完图追加到同一个 case 重审。

## 一句话：怎么跑

```bash
# 网页版（推荐，浏览器里点一点完成）
python3 system/server.py
# 打开 http://localhost:8000

# 命令行版（不用开网页）
python3 system/cli.py review --ocr-text-file system/tests/fixtures/rc-20261104-001-ocr.txt
python3 system/cli.py list
```

零依赖：只用 Python 3 标准库 + 仓库已有的 `src/`，不用装 Flask，
不用 API key，不用联网，不把图发给任何外部服务。

## 系统里有什么

| 部分 | 说明 |
|---|---|
| `system/core.py` | 核心：跑 `src/deterministic_checks.py`、用 `src/apr.py` 反推期数、按 `templates/RC-template.md` 生成 RC 草稿；server 和 cli 共用 |
| `system/server.py` | 网页版：新建 case、上传图片、看检查结果和报告、人工签核、看历史 |
| `system/cli.py` | 命令行版：`review / list / show / signoff` 四个命令 |
| `data/cases/<case-id>/` | 每个 case 的档案：广告图、ocr.txt、checks.json、report.md、case.json（含状态和历史） |
| `system/tests/fixtures/` | 黄金案例的 OCR 文本（RC-20261104-001），用来验证系统 |

## 工作流（和之前定的三层一致）

1. **转录**：把图上文字逐字抄进系统（包括脚注、牌照号、热线、忠告、
   画板 / 水印残留）。转录可以在 Marley 聊天里做，系统不猜。
2. **第 1 层 · 确定性检查（系统自动）**：牌照号、热线、忠告原文、
   APR 是否出现、推广日期、`*` / `^` 脚注是否对应、画板 / 水印残留。
3. **APR 反推（系统自动）**：本金 + APR + 月供 → 对应期数，
   是不是常规期限（12 / 24 / 36 / 48 / 60 / 72 / 84）。
   例如 50,000 本金、1.15%、月供 805 → 约 64.1 个月，不是常规期限。
4. **第 2 层 · LLM / 人工评审（系统里标「待评审」）**：画面语气、
   误导关联、忠告显著性等，仍按 `checklist/hk-checklist.md` 由 Marley 或人工补全。
5. **第 3 层 · 人工签核（系统记录）**：签核人 + 决定（不建议发布 /
   需修改后重审 / 待补充资料）+ 备注，写进 case 历史。

## 系统有意不做的事

- **不做 OCR**：本机没装 tesseract，系统也不会把图发给外部 OCR。
  想接 OCR：本机装好 tesseract 后，在 `core.review()` 前加一步调用即可。
- **不判「合规」**：输出永远只是草稿建议，最终必须人工签核。
- **不编数字**：忠告字号比例、牌照有效性、APR 计算底稿，
  不能确认就写「无法确认，需源档 / 计算底稿 / 注册处复核」。
- **原图不进 Git**：`.gitignore` 已忽略 `*.png / *.jpg` 和 `data/`，
  case 数据只存在本机。

## 验证过的结果（2026-11-06，用黄金案例 RC-20261104-001 的 OCR 文本跑的）

- 确定性检查 5/8 通过；不通过：`promo_date_present`（限时推广没日期）、
  `no_artboard_residual`（画板 4）、`no_watermark`（Sonic.Peng0876 水印）；
  `^` 脚注存在，但只是「优惠受条款及细则约束」通用句，条件仍不足（见报告 C 项）
- APR 反推：50,000 本金、1.15%、月供 805 → 约 64.1 个月，不是常规期限
- 建议结论：不建议发布，风险高；另标高风险：回赠 80,000 大于借款 50,000
- 与人工 RC-20261104-001 v1 的结论一致（不建议发布、高风险）

验证命令：`python3 system/tests/test_system.py`（跑 CLI + 校验上述断言）。

   再定也不迟。
